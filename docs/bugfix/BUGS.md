# BUGS — реестр багов кампании

> Один баг = одна строка. ID выдаётся по порядку (`BF-001`, `BF-002`, …) и не переиспользуется.
> Статус и коммит обновляются в том же коммите, что и фикс (правило R2 в `PROGRESS.md`).
> Подробный разбор (причина, стек, мысли) — в `docs/bugfix/bf/BF-<nnn>.md`, если он нужен.

## Приоритеты

| Приоритет | Что это | Реакция |
|---|---|---|
| **P0** | Паника/краш, потеря данных, повреждение проекта, зависание приложения | берётся первым, всегда с регрессионным тестом |
| **P1** | Неверный результат рендера/экспорта, потеря функциональности, ошибка, которую видит пользователь | в работу после P0 |
| **P2** | Косметика, неудобство, редкий крайний случай, производительность | по остатку |
| **P3** | Мелочи, документация, сообщения об ошибках | когда удобно |

Правило проекта «Never crash» (`AGENTS.md`) важнее приоритета: любой найденный путь паники
становится P0, даже если пользователь его не замечал.

## Статусы

`todo` → `in-progress` → `review` (проверки зелёные, ждёт подтверждения) → `done`;
`blocked` — с причиной в колонке «Заметки»; `wontfix` — с обоснованием.

## Шаблон записи

```markdown
| BF-000 | P1 | render / effectcraft-render | Краткий симптом одной строкой | `cargo test -p effectcraft-render <test>` или шаги CLI/MCP | todo | | | | |
```

И, если нужен разбор:

```markdown
# BF-000 — <симптом>

- **Приоритет:** P0/P1/P2/P3
- **Крейт(ы):** `effectcraft-…`
- **Первый плохой коммит:** `<sha>` (если известен)
- **Воспроизведение:** команды/файл проекта, шаги в UI
- **Ожидаемое / фактическое:** …
- **Причина:** …
- **Фикс:** что изменено и почему именно так
- **Регрессионный тест:** `crates/<crate>/tests/it/<file>.rs::<test>`
- **Проверки:** `check.ps1 -Mode fast` / `-Mode full`, дата
- **Побочные эффекты:** …
```

## Кандидаты на разбор (не подтверждены)

Список открытых багов upstream (на 2026-10-12 в `ROADMAP.md` упомянуты 216 открытых issue, из них
6 крашей: #580, #501, #426, #341, #234, #879). Чтобы превратить их в записи реестра, нужен доступ
к GitHub (сеть) и проверка на этом клоне — без проверки в реестр не вносить.

Локальные источники известных проблем:

- `docs/gaps.md` — ранжированные отставания от After Effects (G1–G9), в том числе
  надёжность/стабильность.
- `ROADMAP.md` — текущий этап, счётчик issue и список крашей.
- Прогон `cargo xtask ci` и `cargo nextest run` — реальные падения на этой машине важнее
  любого списка.
